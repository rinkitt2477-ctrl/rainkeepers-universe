# tests

`check.py` เปิดเว็บใน Chromium จริง (ผ่าน Playwright) ที่ขนาดคอม 1440×900 และมือถือ 390×844 แล้วเลื่อนจริง:

1. ไม่มี JavaScript error
2. มือถือไม่มีเลื่อนด้านข้าง
3. เดินเข้าร้าน: ซูม / ประตู / ห้อง ขยับความเร็วคงที่ และจบที่ห้องเต็มจอ
4. หนังสือบนชั้นเปิด overlay ได้ (หรือเป็นลิงก์ ถ้าใส่ `link` แล้ว)
5. หน้า about: วิดีโอโหลด ขยับตามการเลื่อนความเร็วคงที่ และย้อนกลับได้
6. กระดาษสองแผ่นยังมีขนาดเต็ม และหมอกสำรองทำงานเมื่อวิดีโอโหลดไม่ได้
7. หน้า journal เปิดได้ ไม่ล้นจอ และเช็ดหมอกบนกระจกได้

ทดสอบขณะตั้งค่าลดการเคลื่อนไหวด้วย เพื่อยืนยันว่าแอนิเมชันยังแสดงเต็มตามกติกาเว็บ
การวัดวิดีโอรอให้การเลื่อนและการ seek ถึงเป้าหมายก่อน จึงไม่ขึ้นกับความเร็วถอดรหัสของเครื่อง

ถ้าต้องการเก็บภาพไว้ตรวจด้วยตา ให้ตั้งตัวแปร `RAINKEEPER_QA_DIR` เป็นโฟลเดอร์นอก repository ก่อนรัน

```bash
pip install playwright
python -m playwright install chromium
python tests/check.py     # exit 0 + "ALL PASS" = ผ่าน
```

เพิ่มเทสต์ใหม่ทุกครั้งที่เพิ่มฟีเจอร์ที่ขยับตามการเลื่อนหรือกดได้
