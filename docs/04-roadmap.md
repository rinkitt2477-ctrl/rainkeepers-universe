## A. ค้างอยู่ / ต้องทำก่อน

1. **ใส่ลิงก์ readAwrite** ใน `BOOKS[0].link` เมื่อเจ้าของส่งมา (เมื่อเรื่องเผยแพร่) → เทสต์ว่าเล่มบนชั้นเป็น `<a>` เปิดแท็บใหม่ทั้งคอม/มือถือ
2. **ล้างข้อมูลส่วนตัวในประวัติ git** — commit แรก (`5730252`) ถูกสร้างด้วยชื่อจริงและอีเมลจริงของเจ้าของ ต้อง rewrite author เป็น `ผู้เก็บเสียงฝน <rainkeeper@users.noreply.github.com>` แล้ว force-push **ทำเมื่อเจ้าของอนุมัติเท่านั้น** (ย้อนคืนไม่ได้)
3. **ตัดสินใจเรื่องความเป็นส่วนตัวของ repo** — ทางเลือกที่เสนอเจ้าของไว้: ตั้ง repo เป็น Private + ย้ายโฮสต์ไป Cloudflare Pages (ฟรี, ลิงก์ `.pages.dev` ไม่มีชื่อบัญชี GitHub) ดู docs/05 ยังรอเจ้าของตอบ
4. **แทนข้อมูลตัวอย่าง**: `ENTRIES` หน้า journal (เป็นข้อความเทมเพลต มีตัวละครที่ไม่มีจริง) + ลบป้าย "…เป็นตัวอย่าง" ทั้งสองที่ ถ้ายังไม่มีบันทึกจริง เสนอเจ้าของให้ซ่อนลิงก์ journal ชั่วคราว
5. **ช่องติดต่อหน้า about** ยังเป็น placeholder — ถามเจ้าของว่าจะใส่อะไร (เพจ/โซเชียลแบบใช้นามปากกา) หรือเอาออก

## B. ปรับปรุงที่เจ้าของสนใจ

6. **วิดีโอ room-reveal แนวตั้ง 9:16 สำหรับมือถือ** — ตอนนี้มือถือแนวตั้งเห็นแค่ตู้กลางภาพ ไม่เห็นแมว/หน้าต่าง ทำ prompt ใน docs/07 → encode → โหลดตาม `innerWidth < innerHeight`
7. **เสียงกระดาษ/บรรยากาศหน้า about** (ถ้าเจ้าของอยาก) ใช้ WebAudio เหมือนเสียงฝน ห้ามใช้ไฟล์เสียงมีลิขสิทธิ์
8. **ภาพตัวอย่างเวลาแชร์ลิงก์ (Open Graph)** — `og:title`, `og:description`, `og:image` (ทำภาพ 1200×630 จาก street.jpg) ให้ลิงก์ที่ส่งใน LINE/Facebook มีภาพสวย (noindex ไม่กระทบ)
9. **favicon** รูปร่ม/หยดฝนโทนทอง

## C. เมื่อมีนิยายมากขึ้น

10. เพิ่มเล่มที่ 2+ บนชั้น (`SLOTS` มีตำแหน่งรองรับแล้ว) — ถ้าอยากให้เล่มใหม่ดูสมจริงเหมือนเล่มแรก ต้องสร้างภาพตู้ใหม่ที่มีหลายเล่มแล้ววัดพิกัด
11. ถ้าจะลงเนื้อหาบทในเว็บเอง (ไม่ใช่แค่ลิงก์ readAwrite) ใช้ `chapters` + ระวังเรต 18+ (อาจต้องมีหน้าเตือนอายุ)
12. ระบบนับผู้อ่านแบบไม่เก็บข้อมูลส่วนตัว (เช่น GoatCounter/Cloudflare Web Analytics) — ต้องถามเจ้าของก่อน และต้องอนุญาตโดเมนนั้นใน CSP ถ้ายังจะใช้ใน artifact ของ Claude
