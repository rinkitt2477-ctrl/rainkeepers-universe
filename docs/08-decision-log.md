# 08 · บันทึกการตัดสินใจของเจ้าของ (อย่าย้อนกลับโดยไม่ถาม)

## ตัวตนและชื่อ
- ชื่อเว็บ **The Rainkeeper's Universe** (เดิม "ชั้นหนังสือของ…" ถูกบอกว่าแปลก)
- ร้านหนังสือลึกลับกลางฝน ข้างในอบอุ่นมีโคมไฟ
- หน้า about ชื่อ **ผู้หลงใหลในหยาดฝน** — ไม่มีข้อมูลส่วนตัว ใช้นามปากกาอย่างเดียว ให้ลึกลับ
- สะกด "แชต"

## หน้าร้าน / เดินเข้าร้าน
- เลื่อนจอ = ซูมเข้าประตู แล้วเห็นตู้ในร้าน (ไม่ใช่กดแล้วกระโดด)
- ซูมไม่มากเกิน (ประตูเต็มประมาณ 3/4 ความสูงจอ ไม่ทะลุ)
- **ประตูบานพับขวา** เปิดเข้าในร้าน (เคยเปิดผิดข้าง)
- ป้าย **OPEN** แขวนบนประตู ตำแหน่งปัจจุบันเจ้าของบอก "แบบนี้ดีแล้ว"
- ความยาว `.street` 400vh, ปุ่มเข้าร้าน 6 วิ — เคยบอกว่าเร็วไป
- **ความเร็วต้องคงที่ตลอด** ทั้งหน้าร้านและหน้า about (ขอเมื่อ 25 ต.ค.) ห้ามกลับไปใช้ ease-in-out กับการเลื่อน
- ห้องในร้านต้อง **เต็มจอ** (cover, ชิดบน) — เคยบอกว่าไม่เต็มจอ/ดูถูกขยาย
- ไม่มีภาพห้องซ้อนสองชั้นหลังเดินเข้า

## ตู้หนังสือ
- ตู้จริงสมจริง (จากภาพ) ไม่ใช่ตู้วาดด้วย CSS
- **ไม่มีโคมไฟที่ขยับ/แกว่ง** ("ไร้สาระ") ตัดออกแล้ว
- ชั้นเกือบว่าง มีเล่มเดียว — เล่มทดลองสีแดงเลือดหมูถูกเอาออกแล้ว
- หิ่งห้อยรอบตู้ ไม่ฟุ้งเกิน · ชี้หนังสือแล้วขึ้นชื่อเรื่อง + การ์ดเรื่องย่อ
- หนังสือลิงก์ไป readAwrite (เมื่อมีลิงก์)

## เสียง
- เสียงฝนที่หน้าต่างต้องเด่น ฟ้าร้องนาน ๆ ครั้งและไม่ดังกลบ
- มี slider ปรับระดับเสียง (เคยบอกว่าดังไป)
- ไม่ใช้เสียงจาก YouTube (ติดลิขสิทธิ์) — สร้างในโค้ด

## หน้า about
- ไม่เอาตัวเลขเปอร์เซ็นต์
- กระดาษเก่าสีกาแฟ ใช้ภาพกระดาษจริงของเจ้าของ (`paper.jpg`)
- เนื้อหามาจากข้อมูลนิยายจริง ไม่ใช่ข้อความทั่วไป
- รูปแบบเลื่อน: อ้างอิง "freight scroll hero" (ฉากหลัง sticky + วิดีโอ scrub + ข้อความลอยขึ้นตามแกนกลาง + เมฆ/หมอกกลืนเป็นหน้าเรียบ)
- **กระดาษต้องเป็น 2 แผ่นเต็มแบบเดิม** (จดหมาย + โน้ต) — เคยแยกเป็นเศษกระดาษ 5 ชิ้น เจ้าของบอก "ทำไมต้องแยก แบบเดิมก็ดีอยู่แล้ว"
- วิดีโอ room-reveal ทำโดยเจ้าของด้วย ChatGPT จาก prompt ใน docs/07

## การทำงาน
- ตอบเจ้าของเป็นภาษาไทยก่อนเสมอ, ข้อมูลภายนอกต้องมีแหล่งที่มา
- **ทดสอบจริงก่อนบอกว่าเสร็จ**
- เครื่องเจ้าของเปิด reduced motion แต่ต้องเห็นแอนิเมชันทั้งหมด
- แชร์แบบลิงก์อย่างเดียว ไม่ให้ค้นเจอ
- อยากได้งานที่มีเอกลักษณ์ ความคิดสร้างสรรค์ ไม่ซ้ำแบบเทมเพลต
