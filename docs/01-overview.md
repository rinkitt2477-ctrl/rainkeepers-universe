# 01 · ภาพรวมโปรเจกต์

## แนวคิด

**The Rainkeeper's Universe** — ร้านหนังสือที่เปิดเฉพาะคืนที่ฝนตก (tagline บนหน้าร้าน)
- เจ้าของร้าน = นักเขียนนามปากกา **ผู้เก็บเสียงฝน** ไม่เปิดเผยตัวตน ให้รู้สึกลึกลับ
- คนอ่าน = "คนที่หลบฝนเข้ามา" เดินจากถนนเปียก ผลักประตู เข้ามาเจอตู้หนังสือที่ยังเกือบว่าง
- นิยายเรื่องแรกบนชั้น: **อย่าบอกใครนะ** — BL นิยายแชต กำลังจะลงบน readAwrite
- อารมณ์: อบอุ่นข้างใน เปียกเย็นข้างนอก แสงส้มทองจากโคม ฝนสีฟ้าอมเทา ไม่หวือหวา ไม่เป็นเทมเพลต

## หน้าและการนำทาง (hash routing)

| hash | หน้า | สาระ |
|---|---|---|
| `#` หรือ `#shelf` | หน้าร้าน | `.street` สูง 400vh มีฉาก sticky: ถนน → ซูมเข้าประตู → ประตูเปิด (บานพับขวา) → crossfade เข้าห้อง (`#xf`) ที่มีตู้หนังสือและหนังสือที่กดได้ ด้านล่างมีสารบัญ (`#toc`) |
| `#about` | ผู้หลงใหลในหยาดฝน | วิดีโอ `room-reveal` scrub ตามการเลื่อน + หัวข้อลอยขึ้นแกนกลาง + กระดาษ 2 แผ่น (จดหมาย + โน้ต "สิ่งที่คุณจะได้") → หมอกสีกระดาษ → ส่วนปิดท้าย + ช่องติดต่อ |
| `#journal` | บันทึกข้างหน้าต่าง | กระจกฝ้า (canvas `#fog`) ลากเช็ดได้ + บันทึกจาก `ENTRIES` |
| `#<book id>` เช่น `#secret` | เปิดเล่ม | overlay หน้าปก/สารบัญของเล่มนั้น (ถ้าเล่มยังไม่มี `link`) |

แถบเมนูบน: หน้าร้าน / ผู้หลงใหลในหยาดฝน / บันทึกข้างหน้าต่าง + ปุ่มเปิดเสียงฝน + slider ระดับเสียง (โชว์เมื่อเปิดเสียง)

## ลูกเล่นที่มีอยู่แล้ว

- preloader "กำลังกางร่ม…" + ตัวเลข %
- ฝน canvas หลายชั้นบนถนน + หยดน้ำบนกระจก + ฝนที่หน้าต่างในร้าน
- วิดีโอวนลูปซ้อนบนภาพนิ่ง (ถนน/ในร้าน) เล่นเฉพาะตอนอยู่ในจอ
- ป้าย OPEN แขวนแกว่งบนประตู, เสียงกระดิ่งตอนประตูเปิด
- หิ่งห้อย/ฝุ่นแสงรอบตู้ เมื่อชี้หนังสือจะมีกลุ่มหิ่งห้อยมารวม + การ์ดเรื่องย่อ (tip)
- หนังสือเล่มแรกเป็นภาพสันหนังสือที่ crop จากภาพตู้จริง (ไม่ใช่กล่องวาด)
- เสียงฝนสังเคราะห์ (pink/brown noise + หยดน้ำ + ฟ้าร้องนาน ๆ ครั้ง) เสียงอู้อี้ลงเมื่อเข้าร้าน
- เคอร์เซอร์พิเศษ (เฉพาะเมาส์) แสดงคำกริยา เช่น "เข้าร้าน" "หยิบอ่าน"
- โหมดอ่าน (reader) มีปรับขนาดตัวอักษร จำบทล่าสุดที่อ่าน

## ดีไซน์

**ฟอนต์** (Google Fonts)
- `--f-sign` Prompt — ป้าย หัวข้อ UI
- `--f-body` Sarabun — เนื้อความ
- `--f-hand` Itim — ลายมือ (จดหมาย ลายเซ็น)

**สีหลัก** (`:root`)
- กลางคืน `--night #060a10`, ถนน `--street #0c131b`, ฝน `--rain #a9c1d8`
- ทอง/แสงโคม `--gold #f2b65a`
- ไม้ `--wood #5b3a22`, ข้างในร้าน `--warm #170f09`
- ตัวอักษร `--text #efe7d8`, รอง `--text-soft #b3a892`
- กระดาษหน้า about: ฉากจบ `--pp #d2b98f` (= สีเฟรมสุดท้ายของวิดีโอ room-reveal ต้องตรงกัน), หมึก `--ink2 #2e1c0f`

**หลักการ**
- รูปจริง (สร้างด้วย AI) เป็นฉากหลัก + เอฟเฟกต์โค้ดซ้อนบาง ๆ ไม่ใช่วาดทุกอย่างด้วย CSS
- ภาพเต็มจอแบบ cover, ตำแหน่งปุ่ม/หนังสือคิดเป็น % ของภาพต้นฉบับ
- มือถือ: ห้ามเลื่อนด้านข้าง, ห้องในร้านกว้าง 210vw แต่จัดตู้ไว้กลาง
- การเคลื่อนไหวตามการเลื่อนต้อง **ความเร็วคงที่** (เจ้าของขอ) ไม่มีช่วงช้า-เร็ว-ช้า
