# 06 · การดูแลหลังจากนี้ (สูตรทำงานประจำ)

ทุกสูตร: แก้ → `python tests/check.py` → เปิดดูด้วยตา (คอม + มือถือ) → commit ด้วยนามปากกา → push → เช็กเว็บจริง

## ใส่ลิงก์นิยายบน readAwrite
แก้ `BOOKS[0].link` เป็น URL หน้าเรื่อง (ขึ้นต้น https://www.readawrite.com/...) — ไม่ต้องแก้ที่อื่น เล่มบนชั้นและการ์ดจะเปลี่ยนเอง

## แก้เรื่องย่อ / สถานะ
`synopsis`, `status` (`writing` กำลังเขียน · `done` จบแล้ว · `soon` เร็ว ๆ นี้) — เรื่องย่อยาวประมาณเดิม (การ์ด tip มีที่จำกัด) เช็กว่าการ์ดไม่ล้นจอบนมือถือ

## เพิ่มนิยายเล่มใหม่
เพิ่ม object ใน `BOOKS` (id ไม่ซ้ำ, ภาษาอังกฤษตัวเล็ก) เล่มที่ 2+ จะไปอยู่ตำแหน่ง `SLOTS` เป็นสันหนังสือวาดด้วย CSS สี `color` · ถ้าเกิน 8 เล่มต้องเพิ่ม `SLOTS`

## เพิ่มบทให้อ่านในเว็บ
`chapters: [{ title:"ชื่อบท", text:["ย่อหน้า", "ย่อหน้า"] }]` — ระวังเรต: ช่วง 18+ ไม่ควรลงในเว็บนี้โดยไม่มีหน้าเตือนอายุ

## เพิ่มบันทึกหน้า journal
เพิ่มบนสุดของ `ENTRIES`: `{ date:"2026-11-01", title:"...", text:"..." }` (ใหม่สุดอยู่บน)

## เปลี่ยน/เพิ่มวิดีโอ
- วิดีโอลูป (ถนน/ในร้าน): ต้องกล้องนิ่ง สัดส่วน/องค์ประกอบตรงกับภาพนิ่งทุกพิกเซล (ปุ่มประตูและหนังสือวางทับตามพิกัด)
- วิดีโอ scrub (about): encode ใหม่ให้ seek ไว (keyframe ถี่):
```bash
ffmpeg -i room-reveal.mp4 -an -c:v libx264 -preset slow -crf 25 -pix_fmt yuv420p \
  -g 4 -keyint_min 4 -sc_threshold 0 -bf 0 -movflags +faststart vid/room-reveal-1080.mp4
ffmpeg -i room-reveal.mp4 -an -vf scale=1280:720 -c:v libx264 -preset slow -crf 24 -pix_fmt yuv420p \
  -g 4 -keyint_min 4 -sc_threshold 0 -bf 0 -movflags +faststart vid/room-reveal-720.mp4
```
- ถ้าความยาวคลิปหรือจังหวะเปลี่ยน ปรับ `PULL` ใน `About` (สัดส่วนเวลาที่กล้องถอยจบ เช่น 3.6/6 = .6) และสี `--pp` ให้ตรงกับเฟรมสุดท้าย:
```bash
ffmpeg -sseof -0.05 -i room-reveal.mp4 -frames:v 1 -vf scale=1:1 -f rawvideo -pix_fmt rgb24 - | xxd -p
```
- ไฟล์วิดีโอแต่ละไฟล์ควร < 10 MB

## ปรับเสียงฝน
อยู่ในโมดูล `Sound` — ค่าเริ่ม slider 45 · ถ้าเจ้าของบอกว่าเสียงดัง/ฟ้าร้องกลบ ให้ลด peak ฟ้าร้องหรือเพิ่มช่วงสุ่ม ห้ามเปลี่ยนเป็นไฟล์เสียงจากเว็บอื่น

## แก้ปัญหาที่เคยเจอ

| อาการ | สาเหตุ / ทางแก้ |
|---|---|
| แอนิเมชันหายในเครื่องบางเครื่อง | มีคนใส่ prefers-reduced-motion กลับมา → เอาออก (`REDUCE/CALM = false`) |
| เลื่อนแล้วไม่เข้าร้าน / ซ้อนภาพห้องสองชั้น | ชื่อคลาสชนกัน (`.pin`, `.note`) หรือย้าย `#stageWrap` ออกจาก `#xf` |

| วิดีโอลูปไม่เล่นบนมือถือ | ต้อง `muted playsinline` + `liveLoop` ลองเล่นใหม่ตอนแตะ (มีแล้ว) |
