# 03 · เนื้อหาและข้อมูลที่ใช้

## 1. ข้อมูลในโค้ด (`index.html` บล็อก `/* ===== แก้ไขเนื้อหาตรงนี้ ===== */`)

```js
const AUTHOR = "ผู้เก็บเสียงฝน";
const BOOKS = [{
  id: "secret",                 // ใช้เป็น hash (#secret) — ห้ามซ้ำ
  title: "อย่าบอกใครนะ",
  genre: "BL · นิยายแชต",
  status: "writing",            // writing | done | soon  → STATUS แปลเป็นไทย
  color: "#2f4858", height: 250, icon: "drop", motif: "drops",   // ใช้กับหน้าปก overlay / เล่มถัดไป
  platform: "readAwrite",
  link: "",                     // ← ยังว่าง รอลิงก์หน้านิยายบน readAwrite จากเจ้าของ
  synopsis: "เพื่อนแปดคน โต๊ะเดิมหลังร้านกาแฟ กับแชตกลุ่มที่ไม่เคยเงียบ Milo พูดตรงเสมอ ส่วน Ren ไม่เคยพูดเรื่องตัวเองเลย “อย่าบอกใครนะ” Ren ขอแค่นั้น และ Milo ก็ยอม ปัญหาคือ...ทุกคนรู้มาตั้งแต่แรกแล้ว",
  chapters: []                  // [{ title: "ชื่อบท", text: ["ย่อหน้า 1", "ย่อหน้า 2", ...] }]
}];
const ENTRIES = [ /* บันทึกหน้า journal: { date:"YYYY-MM-DD", title, text } */ ];
const SHOP_OPENED = "2026-10-24";
```

**เมื่อ `link` มีค่า** เล่มบนชั้นจะเป็นลิงก์เปิดแท็บใหม่ไป readAwrite การ์ดเรื่องย่อเขียนว่า "คลิกเพื่ออ่านบน readAwrite ↗"
**เมื่อ `link` ว่าง** กดแล้วเปิด overlay ของเล่มในเว็บ

⚠️ **`ENTRIES` ตอนนี้เป็นตัวอย่างจากเทมเพลต ไม่ใช่ของจริง** (มีชื่อตัวละคร "ภพ" และเรื่อง "บทที่ห้า" ที่ไม่มีอยู่ในนิยาย) ต้องแทนด้วยบันทึกจริงจากเจ้าของ หรือซ่อนหน้า journal — ดู roadmap
⚠️ หน้าร้านมีข้อความ "เนื้อหาในเล่มตอนนี้เป็นตัวอย่าง…" และหน้า journal มี "บันทึกด้านบนเป็นตัวอย่าง" — ลบเมื่อใส่ของจริงแล้ว

## 2. ข้อเท็จจริงเกี่ยวกับนิยาย (ใช้อ้างอิงได้ ห้ามแต่งเพิ่ม)

ที่มา: เอกสาร canon ของเจ้าของ (อยู่ใน Claude Project ไม่ได้อยู่ใน repo นี้) ถ้าต้องเขียนอะไรเกี่ยวกับเนื้อเรื่องเกินจากนี้ ให้ถามเจ้าของก่อน

- ชื่อเรื่อง **อย่าบอกใครนะ** · นามปากกา **ผู้เก็บเสียงฝน** · BL นิยายแชต (Boy Love) บน readAwrite
- สถานะ: ยังไม่เผยแพร่ ตอนแรกกำลังจะลง
- ตัวละครหลัก: **Ren** กับ **Milo** · กลุ่มเพื่อนแปดคน: Milo, Ren, Kin, Tom, Ben, Chip, Nick, Gin
- ฉาก: โต๊ะเดิมหลังร้านกาแฟ + แชตกลุ่ม · เดินเรื่องจากวัยมัธยม (ปัจฉิม) ไปถึงมหาวิทยาลัย
- เรต: ตอนนี้ น.13 → ปรับเป็น 18+ ช่วงมหาวิทยาลัยเมื่อทั้งคู่โตแล้ว
- รายละเอียดที่ใช้ได้: เมาส์สำรองของ Gin, รูปวันปัจฉิม 827 ใบในไดรฟ์ของ Tom
- กฎเรื่อง: เล่าผ่านข้อความเป็นหลัก สิ่งสำคัญอยู่ในสิ่งที่พิมพ์แล้วลบ/อ่านแล้วไม่ตอบ · มี "ผู้บรรยายที่ไม่มีชื่อ" หน้าที่คือเก็บสิ่งที่ไม่มีใครพูดออกมา · ฝนในเรื่องไม่ได้แปลว่าเศร้าเสมอไป (ตกทั้งวันธรรมดา วันใจเต้นแรง วันที่เจ็บ) · เพื่อนทั้งแปดมีชีวิตของตัวเอง ไม่ได้เป็นแค่ตัวประกอบให้คู่หลักรักกัน

## 3. ข้อความหน้า "ผู้หลงใหลในหยาดฝน" (ปัจจุบัน — เจ้าของอนุมัติแล้ว)

- หัวข้อ: ผู้หลงใหลในหยาดฝน · eyebrow: The Rainkeeper · จดหมายหลังเคาน์เตอร์ · บรรทัดรอง: ไม่มีใครรู้ว่าใครเป็นคนเปิดไฟร้านนี้ทิ้งไว้
- **จดหมาย** "ถึงคุณที่หลบฝนเข้ามา" 5 ย่อหน้า (ร้านไม่มีป้าย / เรื่องแรกบนชั้น / เล่าผ่านข้อความ + ผู้บรรยายไม่มีชื่อ / ฝนไม่ได้แปลว่าเศร้า / นั่งได้นานเท่าที่ฝนยังไม่หยุด) ลงชื่อ "— ผู้เก็บเสียงฝน" + ตราประทับ RAINKEEPER EST. ๒๕๖๙
- **โน้ต** "สิ่งที่คุณจะได้จากร้านนี้" 4 ข้อ: แชตกลุ่มที่เหมือนได้นั่งอยู่ด้วย / ความรักที่ไม่รีบ / ความลับที่หวานก่อน แล้วค่อยเจ็บ / เรื่องที่โตไปพร้อมตัวละคร + ป.ล. ตอนแรกกำลังจะลงบน readAwrite เร็ว ๆ นี้
- **ส่วนปิด**: นั่งได้นานเท่าที่ฝนยังไม่หยุด + ตรา + ช่องติดต่อ (ยังเป็น placeholder: "(ใส่อีเมลของคุณ)", "(ใส่ลิงก์)", "(Dek-D / ReadAWrite / Fictionlog)")
- ห้ามใส่: ชื่อจริง ประวัติส่วนตัว การศึกษา เปอร์เซ็นต์/สถิติ
